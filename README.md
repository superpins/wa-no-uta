# 蛙之诗 · Web Edition 1.3

企划・制作：我

一款极短篇视觉小说整活 Demo。前半段按完整 Galgame 的规格制作，包含标题界面、回想模式、CG/角色鉴赏、存读档、系统设置、历史记录、AUTO/SKIP、樱花粒子与本地进度保存。

## 运行

直接双击 `index.html` 即可运行。推荐使用 Chrome / Edge。

若浏览器对本地文件的音频或存储策略较严格，可在项目目录启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

也可以直接部署到 GitHub Pages、Cloudflare Pages、Vercel 等静态站点。

## 操作

- 鼠标左键 / Enter / Space：推进文本
- Ctrl：快速推进
- H：隐藏/显示文字框
- Esc：游戏菜单 / 返回
- 右键：隐藏/显示文字框（可在设置里关闭）

## 资源结构

- `assets/bg/`：标题与开场背景
- `assets/cg/`：6 张伪女主回想 CG
- `assets/character/`：伪女主立绘与主线演出素材
- `assets/audio/`：开场 BGM 与最终演出音频
- `assets/ui/`：UI 小素材

回想模式只展示伪女主相关素材，不展示最终主线角色。

所有游戏状态保存在浏览器 `localStorage` 中。

## v1.3 演出约束

- 「还有……」与「她的笑容。」为不可跳过的节奏段落，最后一句完整停留后才进入最终演出。
- 最终演出只显示一行固定笑声文本，不生成无限“哈”；持续效果由笑声音频承担。
- 回想模式、角色鉴赏、CG 鉴赏与 SPECIAL 始终只展示伪女主包装，不出现奶蛙。
- 标题与说明署名统一为「我」。
