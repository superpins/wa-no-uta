> **愿你也能记住，她那一天的笑容。**

春天又一次来到这座小城。

河岸的樱花沿着旧校舍一路盛开，风从坡道尽头吹来，将花瓣带过窗边，也带回那些几乎已经被忘记的往事。

那一年，我只是一个再普通不过的学生。

上课，放学，绕过熟悉的街道，在没有什么变化的日子里等待下一个明天。我曾以为这样的生活会一直继续下去。

直到那个春日下午。

在漫天飘落的樱花之中，我遇见了她。

我已经记不起那天究竟说了些什么。

只记得风很轻，阳光落在她的身后。

以及——

## 她的笑容。

多年以后，当我再次回想起那个春天，我才发现，有些相遇只需要一瞬间，便足以留在人生之中。

这是关于春天、相遇与笑容的故事。

也是一首献给那个无法忘记之人的诗。
